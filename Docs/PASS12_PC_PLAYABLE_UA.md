# PASS12: керований політ через Zone003 на Windows

18.11.2026. Unity 6000.0.58f2, Mono, Windows x64 Development Player.

Цей прохід додає робочий цикл окремої зони: старт, політ, контакт із
перешкодою або вихід за екран, смерть, повторний запуск, завершення маршруту.
Це ще не повністю відновлена гра: оригінальна кампанія, паливо, порятунок
людей, запуск двигуна, руйнування, меню й звук потребують наступних проходів.

## Запуск

- Сцена: `Assets/Scenes/Escape_Zone003_PC_PLAYABLE_PASS12_VERIFIED.unity`.
- Гравець: `Builds/Windows-PASS12/Escape-PASS12.exe`.
- Space / W / стрілка вгору: почати політ і тримати тягу.
- Відпустити клавішу: падіння за підтвердженими рівняннями.
- R: скинути зону та ракету; Escape: пауза/продовження.

Пауза та екрани старту/повтору/завершення — тимчасова оболонка керування
для ПК на базі наявного OnGUI. Оригінальний інтерфейс і його стани ще не
перенесені. Завершення веде до екрана завершення цієї зони, без переходу
до наступного рівня. Збірка призначена для локальної перевірки.

## Відновлені джерела

`tools/extract_playable_zone.py` читає приватні `level0`, `mainData`,
`sharedassets1.assets` і наявний маніфест ієрархії. Перевіряються версія,
розміри структур, посилання на меші, взаємна симетрія матриці шарів,
CRC32 шляхів анімації, кількість каналів і повне споживання AnimationClip.
Вивід записується в ігнорований `Assets/RecoveredPlayablePass12Local`.

Підтверджено:

| Дані | Значення |
|---|---|
| Кліп зони | `anim_Zone003`, 30 секунд, 60 Hz |
| Кінцева локальна позиція RocketTarget | x = 150, y = 0, z = 0 |
| globalZoneSpeed у level0 | 1.25 |
| zoneSpeedScale | 1 |
| Час проходження маршруту без пауз | 24 секунди |
| ViewpointPivot відносно RocketTarget | x = 5 |
| Канали оригінального кліпу | 49 |
| Перенесені треки | 16 |
| Неперенесені прив'язки скриптів | 7 |
| Нативні колайдери у вибраному піддереві | 284 |
| Типи форм до адаптації Unity6 | 22 MeshCollider, 247 BoxCollider, 15 SphereCollider |
| Колайдери в ієрархії ракети | 22, з них 15 у RocketCollisionController.allColliders |

Рух цілі та рухомих об'єктів оцінюється без підгонки кривих: використані
оригінальні кубічні коефіцієнти StreamedClip. Перенесені треки містять
позиції, quaternion-обертання, масштаб, активність об'єкта й чотири
сигнали play для помп. Точні початкові фази підконтролерів помп ще не
перенесені; їхня відновлена анімація запускається через наявні контролери.

Вертикальні рівняння PASS11 залишені без зміни. `managedExternally` лише
дозволяє новій оболонці задавати порядок викликів. У старих сценах це поле
має значення false, тож їхнє попереднє керування збережене.

## Зіткнення

Оригінал використовує 3D PhysX, а не Physics2D. Перевірка Collider2D у
PASS11 не означала відсутність 3D-форм в APK. Відновлені розміри й центри
боксів, радіуси сфер, посилання на оригінальні collision meshes, trigger
і convex. Повернуто налаштування Rigidbody ракети: mass 1, drag 0,
angularDrag 0.05, useGravity false, constraints 56, Discrete.

Матриця взаємодії шарів з `mainData` застосована через `excludeLayers`
кожного колайдера; глобальні налаштування Physics у проєкті не змінені.
Фільтр `DontHitRocket` відтворено за серіалізованими тегами та власником
оригінального Rigidbody, без зміни глобального TagManager.

Два лазери мають від'ємний масштаб, який BoxCollider Unity6 не підтримує.
Для таких форм створено опуклий MeshCollider з тими самими вісьмома кутами
оригінального боксу та його центром. Трансформації й джерельні ресурси
залишені незмінними. Обидва попередження зникли у виправленій сцені.

Оригінальний ланцюг OnCollisionEnter → фільтр безпечних тегів → hit →
одноразова death відтворено у простій оболонці. Поведінка після смерті
(дим, уламки, електрична відмова, звук) ще не перенесена. Межі виходу за
екран перевіряються за оригінальним OutOfScreenCollider.

У цій окремій зоні геометричні колайдери ввімкнені на весь час активності
зони. Оригінальний RuntimeActivatableCollider вмикав їх за близькістю до
камери. Просторовий менеджер активації, фізика окремих уламків і Rigidbody
людей ще не перенесені; це обмеження точності цього проходу.

## Перевірки

- Unity Pipeline 1.0.0 підключено до Unity Editor через CLI 1.0.1.
- Play Mode: server-side `job wait` підтвердив просування Time.frameCount.
- У живій сцені підтверджено рух цілі, камери й смерть при виході за екран.
- Windows-збірка успішна, 0 помилок; нових помилок Console немає.
- Окремі перевірки з цільовими 30, 60 і 144 FPS успішні: вертикальна
  швидкість, інтегроване положення, нахил за попереднім кадром,
  оригінальний горизонтальний маршрут/темп, камера, пауза/продовження,
  реальний OnCollisionEnter на відновленій перешкоді, смерть і reset.
- Завершення перевірено переходом до кінця оригінального таймлайну.
  Це не тест проходження всього рівня гравцем або автопілотом.
- Початок і середину зони відрендерено у зібраному Windows Player.
  Camera/RenderTexture capture не включає OnGUI-оверлей.
- Старі сцени перевірені за хешами, знятими до PASS12.

Локальні докази: `Reports/pass12-player-audit-30.txt`, аналогічні файли
для 60/144 FPS, PNG, `Reports/pass12-build.txt`, `Logs/pass12-player-*.log`.
Діагностичні ін'єкції доступні лише програмно й використовуються тестом
з аргументом `-escapeZoneAudit <absolute-report-path>`; у звичайному
запуску гравця вони не вмикаються.

## Повторне створення

```text
python tools/extract_playable_zone.py --project "D:\Unity Projects\Escape" --output "D:\Unity Projects\Escape\Assets\RecoveredPlayablePass12Local\zone003.json"
```

У збереженому проєкті, поза Play Mode: меню Escape Recovery → 20 - Recover
Zone003 PC flight and 3D contacts (pass 12). Команда відкриває PASS11 і
зберігає нову сцену з унікальним ім'ям. Вона не перезаписує старі сцени.
`EscapePlayableZonePass12.Build` збирає базову PASS12_VERIFIED.

Перед підключенням Pipeline збережено локальну копію наявних незакомічених
налаштувань у `Reports/PASS12-before`. Зміни користувача в інших файлах
не включаються до коміту. Встановлення CLI та локальне підключення Pipeline
не є частиною публічного ігрового контенту.

У Git потрапляють лише власний код і звіти. APK, DLL, витягнуті криві,
геометрія, сцени, PNG і Windows Player залишаються локальними.
