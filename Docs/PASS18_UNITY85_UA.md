# PASS18: перевірка на Unity 6000.0.85f2

Проєкт відкрито встановленим Unity 6000.0.85f2. ProjectVersion оновлено
до `6000.0.85f2 (b028303d8e7d)`. Ігрові механіки не змінювалися.
Opt-in тест використовує звичайний цикл камер і рахує фактично
відрендерені кадри замість додаткових ручних Camera.Render.

Сцена: `Assets/Scenes/Escape_Zone003_PC_BUGFIX_PASS18.unity`.
Окрема збірка: `Builds/Windows-PASS18-6000.0.85f2/Escape-PASS18.exe`.
Стару збірку `Builds/Windows-PASS18` збережено.

Editor запущено з `-diag-job-temp-memory-leak-validation`.
Перевірено повну Zone003, restart, вихід із Play Mode, оригінальні
поштовхи помпи та кінці всіх дев'яти ліній при 30/60/144 FPS.
Попередження `JobTempAlloc` і `ThreadsafeLinearAllocator` не відтворилися.
Є лише службове попередження про ввімкнену діагностику.

Windows: повна зона з рендером і перевіркою видимості фону на
30/60/144 FPS, дев'ять підбирань і стандартний flight/collision/restart
regression на 60 FPS. Усі прогони з тією ж діагностикою пам'яті.
Усі п'ять пройшли без allocator-попереджень. Фонові камери відрендерили
719 / 1437 / 3444 кадри відповідно. Для графічної перевірки вікно тесту
залишається видимим; runInBackground увімкнено лише в opt-in harness.

Початкові незавершені спроби не зараховуються як успішні. Користувач
повідомив про блокування антивірусом і самостійно додав виняток;
автоматизація налаштувань безпеки не змінювала. Остаточні прогони
виконані до завершення. Editor повторно відкрито без діагностичного
аргументу: Console має 0 errors і 0 warnings.
